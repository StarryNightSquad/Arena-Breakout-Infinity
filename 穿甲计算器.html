暗区突围 · 穿甲伤害计算器V1.0

参数

先选武器，枪管取该枪可换的枪管（固定枪管的枪只有一项），子弹只显示该枪口径下的弹种。 击发威力 = 武器自身 + 枪管，两段自动合计，不再手填。护甲耐久按当前 / 上限取比例，换护甲会自动重置为该护甲满耐。

单发结算

耐久只影响穿不穿：抗穿随耐久按双曲衰减，穿透差变大、概率上升。
耐久不影响穿了之后打多少：伤害系数用标称抗穿，固定不变。把甲打碎的那一发照样减伤，只有耐久归零之后再受击才变成无减伤。

说明

为什么伤害不随耐久变：耐久衰减的是「抗穿」，只作用于判定；结算代入的是护甲标称抗穿。所以同一护甲被同一子弹打，只要还没碎，伤害数字就是同一个。

耐久归零才是分水岭：护甲失效，不再减伤，伤害直接按满伤计算。

穿体概率与击穿护甲概率是两回事：前者是子弹穿过人体继续飞行的概率。

距离削穿透：x = 距离 ÷ 枪管射程，穿透按曲线衰减，穿甲概率跟着掉。

钝伤随距离降低（已实测）：远距离打不穿时吃的钝伤更少。

穿甲伤害也随距离降低，与钝伤共用同一条曲线。甲伤是否随距离变仍未知， 本工具暂按不变处理（源码顶部 DMG_DECAY 可关掉伤害衰减）。

毁甲系数按部位分两档：只有胸部 1.0，腹部/头/四肢等其余部位一律 0.3。本表的掉耐久按胸部算，打其它部位的耐久能多撑约 3.3 倍。

伤害扩散未计入：部位被打空后溢出伤害按约 0.8 倍扩散给其它部位。

满耐久打不进：抗穿随耐久衰减，满耐久时判定用抗穿 = 标称抗穿； 源码里另有 t > 0.9999 → 概率 0 的锁，所以首发即使差几点也必定不穿，掉 1 点耐久才开始有概率。

5–6 级护甲为二值判定：Kp ≥ 0 必穿，Kp < 0 完全不穿，没有中间概率。
