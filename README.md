## 穿甲计算器的判定规则

数据全部来自游戏文件的静态解析（护甲表 + 蓝图 + 主程序反汇编），不是拟合出来的经验公式。

**有效抗穿**

```
t = 当前耐久 ÷ 耐久上限
S = min(1.21 − 50 / (200t + 45), 1) × 标称抗穿
```

耐久系数在 96.55% 以上会被 `min(…, 1)` 截断，也就是说**耐久掉到 96.55% 以下，有效抗穿才开始下降**；满耐久另有一道 `t > 0.9999 → 概率 0` 的锁，所以首发即使只差几点也必定不穿。

**击穿概率（按命中部位分三条路）**

| 命中部位 | 0 < 差额 ≤ 10 | 10 < 差额 ≤ 15 | 5–6 级 |
|---|---|---|---|
| 头盔 / 面罩 / 腿甲 | `0.31 − 0.02 × 差额` | **0** | 同左（不分等级，始终概率判定） |
| 胸甲 1–4 级 | `0.0407 × (21 − 差额)` | `0.0316 × √(21 − 差额)` | — |
| **胸甲 5–6 级** | **二值：差额 ≤ 0 必穿，否则 0** | 同左 | 无中间概率 |

差额 = 有效抗穿 − 有效穿透；钳制线是 `0.8999`，任何算出来 ≥ 0.9 的概率直接按必穿处理。

**甲伤（掉耐久）**

```
每发掉耐久 = 子弹甲伤 × 护甲毁甲系数 × 部位倍率（头 / 胸 1.0，腹部与四肢 0.3）
```

与距离无关：`GetArmorDamageScale` 只读护甲对象上的伤害系数并夹到 ≥ 0，链路里没有距离项，
所以贴脸打和 50 m 外打，掉的耐久完全一样。

## 已知限制

**穿甲计算器**

- 只算击穿与单发伤害，**不计算 BTK**：伤害扩散规则在实战里仍有未定项
- 扩散倍率按实测填「四肢 0.8 / 腹部 1.2」，但靶场与实战是两套环境，这两项目前标注为存疑
- 甲伤已确认**不随距离变化**（`GetArmorDamageScale` 链路无距离项），这一点不再列为未知
- 面罩、腿甲的判定分支按反汇编推断，缺大样本实测验证

**手雷伤害模拟器**

- 收录 12 件投掷物，其中 **T-13 / 阔剑正面 / 阔剑背面 / C4 在游戏内未实装**，数据为代码推断，仅供存档参考
- 掩体只模拟「完全遮挡」一档：GHO-2 / C4 按材质系数衰减，其余投掷物直接 0；
  部分遮挡（露半个身子）的暴露度算法仍未查清
- 多层掩体是逐层相乘还是只取一层，尚未实测（`MaxLayerNumber = 3`）
- 电击雷的眩晕 / 减速参数写在 C++ 里，静态解析读不到
- 头 / 胸的扩散倍率未实测，模拟器按 ×1.0 占位

> 靶场数据不作为校准依据：靶场靶子的扩散倍率（腹部 1.5 / 手臂 0.7 / 腿 1.0）与实战（四肢 0.8 / 腹部 1.2）是两套参数，本仓库结论以反汇编 + 实战实测为准。
