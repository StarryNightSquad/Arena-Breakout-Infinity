# 暗区突围：无限 · 繁星攻略组计算工具

本代码由繁星攻略组制作。

所有工具都是**纯前端网页**，下载后用浏览器打开即可，不需要安装任何环境。

## 包含的工具

| 工具 | 文件 | 内容 |
|---|---|---|
| 穿甲计算器 | `穿甲计算器.html` | 武器 → 枪管 → 子弹 → 护甲，含穿透距离衰减 |
| 手雷伤害模拟器 | `手雷伤害模拟器.html` | 投掷物部位伤害、护甲减伤、衰减曲线、失明 / 眩晕 / 减速 / 耳鸣 |

## 已知限制

**穿甲计算器**

- 受限于技术问题，目前仅支持对护甲击穿情况的计算模拟
- 不支持头盔模拟，因为头盔缺少损毁系数的数据
- 无法计算 BTK，因为伤害扩散规则尚不明确
- 日后会考虑增加对头部与胸部致死情况的计算

**手雷伤害模拟器**

- 收录 12 件投掷物，其中 **T-13 / 阔剑正面 / 阔剑背面 / C4 在游戏内未实装**，数据为代码推断，仅供存档参考
- 爆炸的遮挡机制尚未完全查清，模拟器按无遮挡计算
- 电击雷的眩晕 / 减速参数写在 C++ 里，静态解析读不到
